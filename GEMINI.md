## Getting Started

### Prerequisites

- Node.js (LTS version recommended)
- npm or yarn

### Installation

1.  **Clone the repository (if not already done):**
    \`\`\`bash
    git clone <repository-url>
    cd claudechef
    \`\`\`

2.  **Install frontend dependencies:**
    \`\`\`bash
    cd claudechef
    npm install
    \`\`\`
    or
    \`\`\`bash
    cd claudechef
    yarn install
    \`\`\`

3.  **Install backend dependencies:**
    \`\`\`bash
    cd claudechef/backend
    npm install
    \`\`\`
    or
    \`\`\`bash
    cd claudechef/backend
    yarn install
    \`\`\`

### Running the Application

#### Frontend

To start the frontend development server:

\`\`\`bash
cd claudechef
npm run dev
\`\`\`
This will typically start the React application on `http://localhost:5173` (or another port if 5173 is in use).

#### Backend

To start the backend server:

\`\`\`bash
cd claudechef/backend
npm start
\`\`\`
The backend server will usually run on a different port, often `http://localhost:3000`, as configured in `backend/src/server.js`.

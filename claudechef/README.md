# ClaudeChef

An AI-powered recipe generator. Enter the ingredients you have on hand and get a complete recipe generated by Mistral via the HuggingFace Inference API.

## Tech Stack

- **Frontend:** React 19, Vite, react-markdown
- **Backend:** Node.js, Express
- **AI:** HuggingFace Inference API (Mistral)

## Getting Started

### Prerequisites

- Node.js (LTS recommended)
- A [HuggingFace](https://huggingface.co) account and API token

### Installation

1. Install frontend dependencies:
   ```bash
   npm install
   ```

2. Install backend dependencies:
   ```bash
   cd backend && npm install
   ```

3. Create a `.env` file in `backend/` with your HuggingFace token:
   ```
   HF_TOKEN=your_token_here
   ```

### Running the App

Start the backend (port 3001):
```bash
cd backend && npm start
```

Start the frontend dev server (port 5173):
```bash
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## Usage

1. Type an ingredient into the input field and click **Add ingredient**.
2. Add as many ingredients as you like.
3. Click **Get a recipe** to generate a recipe from your ingredient list.
